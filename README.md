- make.fun's brand badge is on screen from the first frame, as the press pack places it.

## How it was made

My AI agent decided the creative (hook, story, on-screen text, voiceover), fetched make.fun's press pack files fresh from https://make.fun/press, and rendered the video with ffmpeg: press-pack illustrations and screenshots, Inter Bold on-screen text, a gTTS voiceover, a synth music bed, the brand badge overlaid from the first frame, and the referral end card with my code typed in. No TikTok editor, no hand editing.

## This repository

- `VIDEO.json` — the TikTok video URL.
- `main.ts` — copies `VIDEO.json` to `/output` (Node 22). The house reads the video itself from TikTok.
